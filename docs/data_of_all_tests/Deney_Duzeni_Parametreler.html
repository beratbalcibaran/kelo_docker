Experimental setup and parameters

I2MTC 2027 paper, Experiment 0. Data from 12 November 2026. Sources: Marvelmind Dashboard map file (saved 12:45, before all recordings), Motive calibration file, NatNet data descriptions, and the recordings themselves. All tables are also in tablolar\ as CSV; the original files are in kaynak_dosyalar\.

To check before the paper

  • Beacon heights were entered as 240 (metres) in the Dashboard. The intended value was most likely 2.40 m. All four beacons have the same value, so the horizontal (x, y) positions are not affected, but the reported z of the hedgehog is 238.5 m. Measure the real beacon heights and fix the setting. With beacons at 2.40 m, the hedgehog would be at ≈ 2.40 − (240 − 238.47) ≈ 0.87 m above the floor; measure this too.
  • Hedgehog-to-marker offset: estimated from the data as 15.3 cm (run 1) and 18.5 cm (last 40). Measure it with a tape measure.
  • Hardware model names: the files only give type codes (stationary 56, hedgehog 57, modem 48). Fill in the exact product names (e.g. Super-Beacon) from the labels.
  • Radio profile and update-rate setting are stored as indices; read the matching labels in the Dashboard (measured rate: 5.76 Hz).
  • OptiTrack exposure: 400 µs in today's profile (130 µs was used on 6 November). The calibration file stores 100 Hz, but the live rate was 120 Hz (verified from frame numbers).
  • Rigid body: the definition exported here (11 markers) is today's last one; it was re-created several times during the recordings.
  • Room description, floor material, temperature during the test, and the photos of the setup are not in any file.
